# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security and integrity of **Dine Luxe** seriously. If you discover a security issue or concurrency vulnerability (such as a lock bypass, auth leak, or injection attack), please **do not open a public issue**.

Instead, please send an email with reproduction steps to:  
**ronitgupta138@gmail.com**

### What to include
- A clear description of the vulnerability.
- Steps to reproduce the issue (including any race conditions).
- Potential impact and exploit scenario.
- Any suggested remediations or mitigations.

You will receive an acknowledgment within 48 hours, followed by updates until a patch is deployed.
